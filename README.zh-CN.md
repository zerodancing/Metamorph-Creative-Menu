# 安装

1. [下载最新版模组](https://github.com/zerodancing/Metamorph-Creative-Menu/releases/download/latest-build/Metamorph-Creative-Menu.zip)。
2. 启动 Noita，在主菜单中打开 **模组**。
3. 点击 **打开模组文件夹**。
4. 将下载压缩包中的 `metamorph_creative_menu` 文件夹移动到刚打开的 `mods` 文件夹中。如果其中已经有 `metamorph_creative_menu`，请删除旧文件夹，再放入新文件夹。
5. 关闭模组文件夹。
6. 回到模组菜单后点击 **刷新**。列表中应出现 **Metamorph: Creative Menu**。
7. 点击 **允许启用不安全的模组**，直到文字变为红色并显示 **允许启用不安全的模组：已允许**。
8. 点击模组名称，使其高亮，并在名称前出现 **[x]**。这表示模组已经启用。
9. 点击 **开始新游戏并让已启用模组生效**。
10. 选择游戏模式并开始游戏。

# 关于本模组

**Metamorph: Creative Menu (MCM)** 是面向 Noita 的创意菜单与工具集。

它把法术、法杖、物品、材料、天赋、效果、生物、变形、天气、全局世界规则和传送整合在同一套界面中。

MCM 既适合自由的创意玩法，也适合用来试验 Noita 的各种机制。许多操作并不是简单地新建一个实体，而是会考虑法杖、物品、形态、天赋或世界当前已有的状态。

**不需要 Entangled Worlds。** 不安装它时，MCM 仍然是功能完整的单人模组。安装 Entangled Worlds 后，会额外启用一些实验性的多人功能。

# 控制与界面

| 操作 | 按键 |
| --- | --- |
| 打开/关闭创意菜单 | **F4 或 TAB** |
| 恢复人类形态 | **变形期间按 TAB** |
| 控制一个生物 | **G** |
| 绘制所选材料 | **鼠标中键** |

MCM 面板也可以通过普通的物品栏界面打开。

按键可以在 **控制** 页面或模组设置中修改。

设置按键时：

- **DELETE / BACKSPACE** — 清除绑定；
- **ESC** — 取消；
- **R** — 恢复默认绑定；
- **全部重置** — 确认后恢复所有默认绑定。

如果同一个组合键被分配给多个操作，MCM 会显示冲突。

## 创意菜单窗口

窗口可以：

- 移动；
- 调整宽度和高度；
- 从边缘或角落拖动调整大小；
- 最小化；
- 关闭；
- 恢复默认布局。

窗口大小、位置以及上次打开的页面会在下次启动游戏时保留。

大型目录支持滚动，并会自动适应当前窗口大小。

## 搜索

以下目录支持搜索：

- 法术；
- 物品；
- 材料；
- 天赋；
- 生物。

搜索不仅可以匹配当前显示的名称，还可以匹配英文名称、本地化键、技术标识符或 XML 路径。

搜索不区分大小写，并且对较长词语中的少量拼写错误具有一定容错能力。

MCM 界面提供 11 种语言。对于普通的游戏内容，会尽量使用 Noita 自身的本地化名称。

# 法术

法术页面不仅可以浏览目录，还可以直接操作当前玩家实际拥有的法术。

同时可以看到：

- 当前法杖槽位；
- **始终施放**；
- 法术物品栏；
- 法术目录。

## 快速替换

选中法杖中的某个槽位，然后在目录中用左键点击所需法术，即可把它放入该槽位。

## 拖放

已有法术可以在以下位置之间移动：

- 法杖槽位之间；
- 移入 **始终施放**；
- 从 **始终施放** 移回普通槽位；
- 移入法术物品栏中的指定槽位；
- 从物品栏移回法杖；
- 移到游戏世界中；
- 移入垃圾桶。

对于已经存在的法术卡，MCM 会尽量移动原本的游戏实体，而不是另建一份副本。这样可以保留卡片已经被修改过的状态，包括其他模组添加的状态。

在新的目标位置得到确认前，原法术会保留在原处。失败或不允许的操作不应销毁原卡片。

## 始终施放

永久法术拥有独立区域。

在普通槽位与 **始终施放** 之间移动法术时，MCM 会考虑法杖容量，以保持普通槽位结构正确。

## 撤销 / 重做

对于法杖内部的修改，MCM 提供有限的 **撤销 / 重做** 历史记录。

它适用于能够仅根据法杖自身状态安全恢复的操作。

把真实法术移到外部世界或普通游戏物品栏后，仅靠恢复法杖状态并不总能正确撤销，因此这类操作不一定可以撤销。

# 法杖

MCM 提供完整的当前法杖编辑器。

可以修改：

- 槽位数；
- 每次施法的法术数量；
- 充能时间；
- 施法间隔；
- 散射；
- 投射物速度倍率；
- 最大法力；
- 法力回复；
- 后坐恢复；
- 法杖等级；
- 乱序；
- **无需充能** 模式。

还可以修改外观和相关参数：

- 显示名称；
- 锁定；
- 法杖图像；
- 图像偏移；
- 发射点。

另有用于选择法杖外观的可视化目录。

## 法杖预设

可以保存一根法杖，并在之后再次使用它保存下来的状态。

保存内容包括：

- 属性；
- 法力；
- 外观；
- 普通法术；
- **始终施放**；
- 卡片位置；
- 剩余使用次数；
- 卡片冻结状态。

保存的法杖可以跨不同游戏世界以及后续启动继续使用。

### 应用

**应用** 会把保存的状态应用到玩家当前手持的法杖上。

### 复制

**复制** 会根据保存状态创建一根独立的法杖副本。

如果快捷物品栏中有合适的空位，新法杖会放入该位置；否则会生成在玩家附近的游戏世界中。

如果创建过程无法正确完成，MCM 会尽量删除未完成的实体。

# 物品与液体

## 物品

在目录条目上点击 **左键** 会在玩家附近生成一个物品。

点击 **右键** 会尝试把物品直接放入物品栏。

也可以拖动物品：

- 到快捷物品栏中的合适区域；
- 拖出菜单，放到游戏世界中选定的位置。

如果卡片在菜单内部松开，但没有有效目标，则操作会取消。

目录中的条目是模板，因此生成物品后，目录条目本身不会消失。

MCM 会遵循 Noita 快捷物品栏中法杖槽和物品槽的正常分区，不应无故替换其中已有的物品。

## 液体

MCM 可以创建装有指定液体的真实游戏容器。

创建出的容器仍然是普通的 Noita 物品：

- 可以放在物品栏中；
- 可以丢到世界里；
- 可以被打碎；
- 会洒出其中内容；
- 会参与正常的材料反应。

# 材料

材料目录由当前 Noita 实例中已经注册的物质动态构建。

其中包括多种材料类型，例如：

- 液体；
- 粉末；
- 气体；
- 火焰；
- 固体；
- 静态材料；
- 使用特殊显示方式的材料。

如果其他已启用模组正确地向 Noita 注册了自己的材料，它也可能出现在 MCM 中。

## 绘制材料

1. 选择材料。
2. 选择画笔大小。
3. 点击 **开始绘制**。
4. 关闭物品栏。
5. 在游戏世界中按住已绑定的绘制按键。

默认使用 **鼠标中键**。

打开物品栏会结束绘制模式。

## 材料行为

MCM 放置的是游戏世界中的真实材料，而不是装饰性粒子。

放入世界后，它们仍然遵循 Noita 的正常模拟规则：

- 液体会流动；
- 粉末会散落；
- 气体会扩散；
- 火焰会与环境互动；
- 物质会发生反应；
- 不稳定材料可能转化为其他材料。

针对不同材料类型，MCM 会使用合适的放置方式；对于普通模组手段无法正确处理的情况，还会使用 NoitaPatcher 提供的额外能力。

# 天赋

## 生成天赋

点击 **左键** 会在游戏世界中生成所选天赋。

可以像普通 Noita 天赋一样拾取它。

## 获得天赋

MCM 可以一次获得：

- 1 份；
- 10 份；
- 100 份。

批量获得会分步处理，避免在同一帧中执行大量高开销操作。

界面会显示任务进度，也可以取消后续处理。取消前已经成功获得的份数会保留在玩家身上。

## 移除天赋

安全移除天赋远比获得天赋复杂。

有些天赋会同时改变多个游戏系统、创建实体或触发效果，而这些变化并不存在统一的逆向操作。

因此，MCM 只会移除那些能够较可靠地执行逆向恢复的受支持变化。

模组会尽量只撤销相应天赋应用时产生的状态，而不会无必要地重置玩家的其他效果和参数。

# 效果

MCM 可以应用和移除受支持的：

- 游戏效果；
- 与材料相关的状态。

移除时，模组会尽量避免影响属于天赋或其他游戏系统的无关状态。

这样可以清除 MCM 自己施加的效果，而不会无条件删除玩家身上所有相似状态。

# 生物与变形

## 生成生物

点击 **左键** 会在玩家附近生成所选生物。

也可以把生物卡片拖出菜单，在游戏世界中的指定位置生成它。

在受支持条目上点击 **右键** 会尝试把当前玩家变形成对应形态。

## 形态兼容性

Noita 中的生物在内部结构上差异很大。

因此，MCM 会按照精确的 XML 路径区分变形目标，不会因为名称或外观相似就自动把所有生物视为可互换。

变形时，MCM 会使用所选形态本身的能力，并在必要时为特定生物应用独立的兼容性规则。

# 变形后的返回与形态死亡

可以通过已绑定的返回操作恢复人类形态，默认按键是 **TAB**。

MCM 会先使用 Noita 正常的变形结束机制。对于更复杂的情况，还提供通过 NoitaPatcher 进行的额外恢复。

模组也会处理受支持的临时形态遭受致命伤害的情况。

这时 MCM 会尝试：

- 保留死亡形态的尸体；
- 恢复人类玩家；
- 恢复控制；
- 保留物品栏；
- 恢复与玩家相关的状态。

这并不是绝对无敌。来自其他模组的异常死亡方式、不兼容模组或 Noita 内部故障仍可能绕过正常恢复机制。

# 控制已有生物

除了从目录选择形态外，MCM 还可以控制 **已经存在于游戏世界中的生物**。

默认按键为 **G**。

把光标移到合适的目标上，然后使用已绑定的操作。

MCM 会检查目标生物，变形成兼容形态，并且只有在确认成功后才把原实体从世界中移除。

如果变形没有成功，原生物不应直接消失。

这个功能不限于 MCM 的静态目录。由其他模组添加的合适生物也可以通过检查，不过无法保证与所有第三方实体都兼容。

# 玩家

**玩家** 是生物目录中的特殊条目。

它不是普通的变形形态。

点击 **左键** 会创建一个独立角色，MCM 会尝试复制：

- 玩家外观；
- 最大生命值。

在 **玩家** 条目上点击 **右键** 不会把正常玩家变形成该实体。

如果玩家已经处于人类形态，该操作不会产生变化；如果玩家当前变形成其他生物，则会执行恢复人类形态。

# 天气与时间

MCM 可以修改：

- 时间；
- 天气预设；
- 各个受支持的天气参数。

既可以强制设置某个状态，也可以随后解除 MCM 对相应参数的控制。

例如，在强制设定时间之后，可以再次恢复 Noita 自然的时间流逝。

# 世界规则

**规则** 页面用于更深入地修改游戏世界的行为。

根据具体规则，可以控制例如：

- 生物之间的关系；
- 金币；
- 法术使用；
- 战争迷雾；
- 特定击杀奖励；
- 治疗掉落；
- 血液；
- 重力；
- 物理行为；
- 踢击力量；
- 物理连接；
- 昼夜循环；
- 其他受支持的全局参数。

MCM 规则的核心特点是这些修改被设计为 **可逆**。

对于受支持的设置，模组会保存初始状态，并允许把参数恢复到正常值。

如果某条规则使用倍率，新值会相对于基础状态计算，而不是不断在已经修改过的结果上继续相乘。

需要修改大量实体或物理对象的操作会分步执行，避免在点击按钮的那一刻尝试一次处理整个世界。

# 传送

MCM 可以快速前往预设的游戏位置，包括：

- 主路线上的地点；
- 神圣山；
- 大型支线区域；
- 其他受支持地点。

传送前，模组可以先加载目标区域，并尝试在附近寻找空闲位置，避免把玩家直接放进实心墙体或其他障碍中。

# Entangled Worlds

**Entangled Worlds / Noita Proxy 是可选的。**

没有它时，MCM 仍可完整用于单人游戏。

安装 Entangled Worlds 后，会启用额外的实验性多人功能。

为了获得更稳定的兼容性，建议所有参与者使用相同版本的 MCM。

## 物品、法杖与法术

在可行的情况下，世界中的物品和被丢出的法术会使用 Entangled Worlds 的标准机制。

物品栏变化也可以通过 Entangled Worlds 传递。

## 天赋

MCM 生成的天赋仍然是真实的游戏实体，并会尽可能通过 Entangled Worlds 的普通世界物品系统同步。

## 材料

材料绘制具有实验性的多人支持。

MCM 会同步受到影响的世界区域，使结果能够出现在其他参与者的游戏中。

为了正确工作，相应材料也必须存在于另一位玩家的游戏中。如果双方模组组合不同，则无法保证所有材料都显示一致。

## 天气与世界规则

受支持的天气和全局规则变化可以通过 Entangled Worlds 同步。

## 变形与控制生物

使用 Entangled Worlds 时，变形具有额外的联机支持。

控制一个已经存在的生物时，模组还会考虑该目标的网络状态。如果 MCM 无法足够可靠地判断原实体是否可以删除，就会选择保留它。

## 玩家

通过 Entangled Worlds 游玩时，也支持创建特殊的 **玩家** 实体。此时它会复制创建者的皮肤颜色。

## 玩家间传送

启用 Entangled Worlds 后，传送页面会显示可用的其他玩家。

**前往** 会把你传送到所选玩家附近。

**传送过来** 会向所选玩家发送安全传送到你身边的请求。

两种操作都会尽量使用目标点附近的空闲位置。

## 限制

Entangled Worlds 支持仍然属于实验性功能。

**在多人游戏中，变形成体型巨大或包含多个关节的首领可能导致性能严重下降，甚至实际上破坏当前游戏会话。**

Noita 的完整同步非常困难，尤其是在以下内容同时发生变化时：

- 像素世界；
- 材料；
- 物理对象；
- 复杂生物和首领；
- 其他模组的内容。

因此，MCM 不保证所有可能状态都能完美同步。

# NoitaPatcher 与不安全模组

MCM 的完整版本包含 **NoitaPatcher**。

它用于实现普通 Noita 模组手段不足以完成的功能，尤其是以下机制中的一部分：

- 复杂变形后的恢复；
- 操作游戏实体；
- 操作游戏世界；
- 放置某些材料；
- 扩展兼容性。

因此，完整版本需要允许 **不安全模组**。

NoitaPatcher 已经包含在 MCM 的可安装构建中，不需要另外安装。

# 故障排除

## MCM 无法加载

确认解压后存在：

```text
Noita/mods/metamorph_creative_menu/mod.xml
```

并检查：

- MCM 已在 **模组** 菜单中启用；
- 名称前有 **[x]**；
- 显示 **允许启用不安全的模组：已允许**；
- 游戏是带着已启用模组启动的。

## 使用 NoitaPatcher 的功能无法工作

确认存在：

```text
metamorph_creative_menu/NoitaPatcher/noitapatcher.dll
```

并确认已允许 **不安全模组**。

## 无法从形态恢复

尝试使用已绑定的返回操作，默认是 **TAB**。

如果问题反复出现，报告时最好提供：

- 生物的准确名称；
- XML 路径（如果知道）；
- 通过什么方式获得该形态；
- 普通返回是否有效；
- 问题是否只在受到致命伤害后出现；
- 是否使用 Entangled Worlds。

## Entangled Worlds 问题

请检查：

- 参与者是否使用相同版本的 MCM；
- Entangled Worlds 版本是否兼容；
- 如果问题涉及其他模组添加的材料或生物，各方是否使用相同的模组组合。
