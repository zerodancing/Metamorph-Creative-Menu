# Тест 36

- `water_static` доступна для рисования в «Статике», а через поиск — из любой категории материалов, в том числе из открываемых по умолчанию «Жидкостей». Поиск теперь охватывает весь каталог. Очистка строки возвращает выбранную категорию.
- Добавлен дополнительный сбор имён из `data/materials.xml`, включая `CellDataChild`. В каталог попадают только реально доступные игре определения. Материалы других модов из штатных списков API сохраняются.
- Устранены три причины потери фокуса при первом вводе: отключённое управление после клика по строке, изменение идентификаторов следующих кнопок при появлении «X», ошибочная обработка задержки первого поиска как возврата после Alt-Tab.
- Пока поле ввода имеет фокус, сохраняется состояние штатного инвентаря. Ввод `i` или переназначенной клавиши инвентаря не должен закрывать меню либо открывать инвентарь за ним. После выхода из поля обычные клавиши снова работают.

Проверки: 266 автоматических проверок прошли. Проверка полноты охватывает все 466 уникальных имён из приложенного файла материалов, включая наследуемые определения, и дополнительный материал мода. Для проверки восстановления в тесте намеренно убраны `water_static` и каждое пятое определение из списков API. Проверены выбор `water_static` для кисти, поиск по всем категориям, сохранение фокуса и обработка переключения инвентаря до/после кадра меню.

Новые регрессионные сценарии отдельно запущены на коде теста 35: ошибки воспроизводятся. На тесте 36 эти сценарии проходят. Это автоматические проверки с имитацией API; сама Noita и сетевой сеанс EW здесь не запускались.

Установка: закрой игру и замени папку `mods/metamorph_creative_menu` папкой из архива.
