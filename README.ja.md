# インストール

1. [最新版をダウンロード](https://github.com/zerodancing/Metamorph-Creative-Menu/releases/download/latest-build/Metamorph-Creative-Menu.zip)します。
2. Noita を起動し、メインメニューから **MOD** を開きます。
3. **MOD フォルダを開く** を押します。
4. ダウンロードしたアーカイブ内の `metamorph_creative_menu` フォルダを、開いた `mods` フォルダへ移します。すでに `metamorph_creative_menu` がある場合は、古いフォルダを削除して新しいものに置き換えてください。
5. MOD フォルダを閉じます。
6. MOD メニューで **更新** を押します。一覧に **Metamorph: Creative Menu** が表示されます。
7. **安全でない MOD** を押し、表示が赤くなって **安全でない MOD：許可** となるようにします。
8. MOD 名を押して明るく表示され、名前の前に **[x]** が付くようにします。これで MOD が有効です。
9. **有効な MOD を使って新しいゲームを開始** を押します。
10. ゲームモードを選んでプレイします。

# この MOD について

**Metamorph: Creative Menu (MCM)** は Noita 向けのクリエイティブメニュー兼ツール集です。

呪文、杖、アイテム、マテリアル、パーク、効果、モブ、変身、天気、グローバルなワールドルール、テレポートを 1 つのインターフェースにまとめています。

MCM は自由なクリエイティブプレイにも、Noita の仕組みを試す用途にも使えます。多くの操作は単に新しいエンティティを生成するのではなく、すでに存在する杖、アイテム、形態、パーク、ワールドの状態を考慮して行われます。

**Entangled Worlds は不要です。** 導入していなくても、MCM は完全なシングルプレイヤー MOD として動作します。Entangled Worlds を導入すると、追加の実験的なマルチプレイヤー機能が有効になります。

# 操作とインターフェース

| 操作 | キー |
| --- | --- |
| クリエイティブメニューを開閉 | **F4 または TAB** |
| 人間形態に戻る | **変身中に TAB** |
| モブを操作する | **G** |
| 選択したマテリアルで描画 | **マウス中央ボタン** |

MCM パネルは通常のインベントリ画面からも利用できます。

キー割り当ては **操作** セクションまたは MOD 設定で変更できます。

キーを割り当てている間は：

- **DELETE / BACKSPACE** — 割り当てを消去
- **ESC** — キャンセル
- **R** — 初期値に戻す
- **すべてリセット** — 確認後、すべての割り当てを初期値に戻す。

同じキーの組み合わせが複数の操作に割り当てられている場合、MCM は競合を表示します。

## クリエイティブメニューのウィンドウ

ウィンドウは次のように操作できます：

- 移動
- 幅と高さの変更
- 辺や角をドラッグしてサイズ変更
- 最小化
- 閉じる
- 初期配置に戻す。

サイズ、位置、最後に開いていたセクションはゲームを終了しても保存されます。

大きなカタログではスクロールが使われ、現在のウィンドウサイズに自動で合わせて表示されます。

## 検索

検索できるカタログ：

- 呪文
- アイテム
- マテリアル
- パーク
- モブ。

表示名だけでなく、英語名、ローカライズキー、技術的な識別子、XML パスも検索対象にできます。

大文字と小文字は区別されず、十分に長い単語では小さな入力ミスもある程度許容されます。

MCM のインターフェースは 11 言語に対応しています。通常のゲーム内容については、可能な限り Noita 本体の翻訳が使われます。

# 呪文

呪文セクションでは、カタログだけでなく、現在のプレイヤーが実際に持っている呪文も操作できます。

同時に利用できるもの：

- アクティブな杖のスロット
- **常時詠唱**
- 呪文インベントリ
- 呪文カタログ。

## 素早い置き換え

杖の特定のスロットを選び、カタログ内の目的の呪文を左クリックすると、そのスロットに設定されます。

## ドラッグ

既存の呪文は次の場所へ移動できます：

- 杖のスロット間
- **常時詠唱** へ
- **常時詠唱** から通常スロットへ
- 呪文インベントリの指定スロットへ
- インベントリから杖へ
- ゲームワールドへ
- ごみ箱へ。

既存のカードについては、新しいコピーを作るのではなく、元のゲームエンティティそのものを移動するよう MCM は試みます。これにより、他の MOD が加えたものを含む、変更済みのカード状態を保持できます。

移動先が確定するまでは元の呪文がその場に残ります。失敗した操作や許可されていない操作で元のカードが失われることはありません。

## 常時詠唱

常時発動する呪文には専用の領域があります。

通常スロットと **常時詠唱** の間で移動する際には杖の容量が考慮され、通常スロットの構造が崩れないように処理されます。

## 元に戻す / やり直す

杖内部の変更には、限定的な **元に戻す / やり直す** 履歴があります。

杖そのものの状態から安全に復元できる操作に適用されます。

実際の呪文を外部のゲームワールドや通常のインベントリへ渡した場合、杖の状態を戻すだけでは正しく元に戻せないことがあるため、そうした操作は必ずしも取り消せません。

# 杖

MCM にはアクティブな杖を編集するための一式の機能があります。

変更できる項目：

- スロット数
- 同時詠唱数
- リチャージ時間
- 詠唱間隔
- 拡散
- 発射物の速度倍率
- 最大マナ
- マナ回復
- 反動回復
- 杖のレベル
- シャッフル
- **リロードなし**。

外見と関連設定も変更できます：

- 表示名
- ロック
- 杖の画像
- 画像の位置ずれ
- 発射位置。

杖の外見を選ぶための視覚的なカタログもあります。

## 杖プリセット

杖の状態を保存して、あとから再利用できます。

保存される内容：

- 性能
- マナ
- 外見
- 通常の呪文
- **常時詠唱**
- カードの配置
- 残り使用回数
- カードの凍結状態。

保存した杖は、別のゲームワールドや Noita の次回以降の起動でも利用できます。

### 適用

**適用** は保存した状態を、プレイヤーが現在持っている杖に反映します。

### コピー

**コピー** は保存した状態から別個の杖を作成します。

クイックインベントリに適切な空き枠がある場合、新しい杖はそこに入ります。空きがなければゲームワールドのプレイヤー付近に生成されます。

正常に作成を完了できなかった場合、MCM は未完成のエンティティを削除するよう試みます。

# アイテムと液体

## アイテム

カタログの項目を **左クリック** すると、プレイヤーの近くにアイテムを 1 個生成します。

**右クリック** すると、アイテムを直接インベントリへ渡すよう試みます。

アイテムをドラッグして：

- クイックインベントリの適切な領域へ
- メニュー外の、ゲームワールド内で選んだ位置へ

移動することもできます。

有効な移動先がない状態でメニュー内にドロップした場合、操作はキャンセルされます。

カタログの項目はひな形なので、アイテムを生成しても一覧から消えません。

MCM は Noita のクイックインベントリにある杖用とアイテム用の通常の区分を考慮し、すでに入っているアイテムを理由なく置き換えないようにします。

## 液体

MCM は選択した液体入りの実際のゲーム容器を作成できます。

作成された容器は通常の Noita アイテムとして動作します：

- インベントリに入れられる
- ワールドへ捨てられる
- 壊れる
- 中身がこぼれる
- 通常のマテリアル反応に参加する。

# マテリアル

マテリアルカタログは、現在の Noita に登録されている物質から構築されます。

含まれる種類の例：

- 液体
- 粉末
- 気体
- 火
- 固体
- 静的マテリアル
- 特殊な表示方法を持つマテリアル。

別の有効な MOD が Noita に独自のマテリアルを正しく追加している場合、それも MCM に表示されることがあります。

## マテリアルを描画する

1. マテリアルを選びます。
2. ブラシサイズを選びます。
3. **描画開始** を押します。
4. インベントリを閉じます。
5. ゲームワールドで割り当てた描画ボタンを押し続けます。

初期設定では **マウス中央ボタン** です。

インベントリを開くと描画モードが終了します。

## マテリアルの挙動

MCM が配置するのは装飾用の粒子ではなく、ゲームワールドの実際のマテリアルです。

配置後も Noita の通常のシミュレーションに従います：

- 液体は流れる
- 粉末は崩れ落ちる
- 気体は広がる
- 火は周囲と反応する
- 物質同士が反応する
- 不安定なマテリアルは別の物質へ変化することがある。

種類ごとに適切な配置方法を使い、通常の MOD 機能だけでは正しく扱えない場合には NoitaPatcher の追加機能も利用します。

# パーク

## パークを生成する

**左クリック** で選択したパークをゲームワールドに生成します。

通常の Noita のパークと同じように拾えます。

## パークを取得する

MCM では次の数を取得できます：

- 1 個
- 10 個
- 100 個。

大量取得は、重い処理を 1 フレームにまとめて実行しないよう段階的に行われます。

インターフェースには進行状況が表示され、以降の処理を中止することもできます。中止するまでに正常に取得できた分はプレイヤーに残ります。

## パークを削除する

パークを安全に削除することは、取得するよりはるかに難しい処理です。

一部のパークは複数のゲームシステムを同時に変更したり、エンティティを生成したり、単一の共通手順では元に戻せない効果を発生させたりします。

そのため MCM は、十分に確実な逆操作を行える対応済みの変更だけを削除します。

他の効果やプレイヤー設定を不必要にリセットせず、該当するパーク取得によって作られた状態だけを元に戻すよう試みます。

# 効果

MCM では次の対応済み状態を付与・削除できます：

- ゲーム内効果
- マテリアルに関連する状態。

削除時には、パークや別のゲームシステムに属する無関係な状態を巻き込まないようにします。

これにより、似た状態をすべて無条件に削除せず、MCM 自身が扱う効果だけを消せます。

# モブと変身

## モブを生成する

**左クリック** で選択したモブをプレイヤーの近くに生成します。

モブのカードをメニュー外へドラッグし、ゲームワールドの指定位置に生成することもできます。

対応している項目を **右クリック** すると、現在のプレイヤーをその形態へ変身させようとします。

## 形態の互換性

Noita のモブは内部構造が大きく異なります。

そのため MCM は正確な XML パスで変身対象を区別し、似たモブを自動的に同じものとして扱いません。

変身時には選択した形態の能力を利用し、必要に応じて特定のモブ向けに個別の互換性処理を適用します。

# 変身後の復帰と形態の死亡

割り当てた操作で人間形態に戻れます。初期設定は **TAB** です。

MCM はまず Noita 通常の変身終了処理を使います。複雑な場合には NoitaPatcher を使った追加の復元処理もあります。

また、一時的な形態が致命的なダメージを受けた場合の対応済み状況も処理します。

その場合 MCM は次の処理を試みます：

- 死亡した形態の死体を残す
- 人間のプレイヤーを復元する
- 操作を戻す
- インベントリを保持する
- プレイヤーに関連する状態を復元する。

これは完全な不死ではありません。他の MOD による特殊な死亡方法、互換性のない MOD、Noita 内部の不具合などでは通常の復元処理が働かないことがあります。

# 既存のモブを操作する

カタログから形態を選ぶだけでなく、MCM は **すでにゲームワールドに存在するモブ** を操作できます。

初期設定のキーは **G** です。

適切な対象にカーソルを合わせ、割り当てた操作を使います。

MCM は対象を確認して互換性のある形態へ変身し、成功が確認された場合にだけ元のエンティティをワールドから取り除きます。

変身に失敗した場合、元のモブがそのまま消えることはありません。

この機能は MCM の固定カタログだけに限定されません。別の MOD が追加した適切なモブも確認対象になりますが、あらゆる外部エンティティとの互換性を保証するものではありません。

# プレイヤー

**プレイヤー** はモブカタログにある特殊な項目です。

通常の変身形態ではありません。

**左クリック** すると別個のキャラクターを作成し、MCM は次の要素をコピーしようとします：

- プレイヤーの外見
- 最大体力。

**プレイヤー** の項目を **右クリック** しても、通常のプレイヤーがこのエンティティへ変身することはありません。

すでに人間形態なら何も変化しません。別のモブへ変身中なら、人間形態への復帰が行われます。

# 天気と時間

MCM では次の項目を変更できます：

- 時刻
- 天気のプリセット
- 個別の対応済み天気パラメータ。

必要な状態を固定することも、あとからそのパラメータを MCM の制御から解放することもできます。

たとえば時刻を固定したあと、Noita 本来の時間経過に戻すことができます。

# ワールドルール

**ルール** セクションでは、ゲームワールドの挙動をさらに深く変更できます。

ルールによって、たとえば次の項目を操作できます：

- モブ同士の関係
- ゴールド
- 呪文の使用
- 戦場の霧
- 特定の倒し方に対する報酬
- 回復アイテムのドロップ
- 血液
- 重力
- 物理挙動
- キックの強さ
- 物理ジョイント
- 昼夜サイクル
- その他の対応済みグローバル設定。

MCM のルールは **元に戻せる変更** として設計されている点が重要です。

対応済みの設定では元の状態を保存し、通常値に戻せます。

倍率を使うルールでは、すでに変更済みの結果へ何度も掛け合わせるのではなく、基準状態をもとに新しい値を計算します。

多数のエンティティや物理オブジェクトを変更する操作は段階的に実行され、ボタンを押した瞬間にワールド全体を一度に処理しないようになっています。

# テレポート

MCM では用意されたゲーム内地点へ素早く移動できます。例：

- メインルート上の地点
- 聖なる山
- 大きな脇道エリア
- その他の対応済み地点。

テレポート前に目的地周辺を読み込み、固い壁や障害物の中へ直接出現しないよう、近くの空き場所を探します。

# Entangled Worlds

**Entangled Worlds / Noita Proxy は任意です。**

なくても MCM はシングルプレイヤーで完全に動作します。

Entangled Worlds を導入すると、追加の実験的なマルチプレイヤー機能が有効になります。

安定した互換性のため、すべての参加者で同じ MCM バージョンを使うことを推奨します。

## アイテム、杖、呪文

可能な場合、ワールド内のアイテムや捨てた呪文は Entangled Worlds の通常の仕組みを使います。

インベントリの変更も Entangled Worlds 経由で共有される場合があります。

## パーク

MCM が生成したパークは実際のゲームエンティティのままで、可能な限り Entangled Worlds の通常のワールドアイテム同期を利用します。

## マテリアル

マテリアル描画には実験的なマルチプレイヤー対応があります。

MCM は変更されたワールド領域を同期し、他の参加者側にも結果が現れるようにします。

正しく動作するには、相手側にも同じマテリアルが存在する必要があります。導入している MOD の組み合わせが違う場合、すべてのマテリアルが同じように表示されるとは限りません。

## 天気とワールドルール

対応済みの天気やグローバルルールの変更は Entangled Worlds 経由で同期できます。

## 変身とモブ操作

Entangled Worlds 使用時、変身には追加のマルチプレイヤー対応が行われます。

すでに存在するモブを操作する場合、その対象のネットワーク状態も考慮されます。元のエンティティを安全に削除できると十分確実に判断できない場合、MCM は削除せず残すことを優先します。

## プレイヤー

Entangled Worlds でのプレイ中も、特殊な **プレイヤー** エンティティを作成できます。この場合、作成した人のスキン色がコピーされます。

## プレイヤー間テレポート

Entangled Worlds が有効な場合、テレポートセクションに利用可能な他のプレイヤーが表示されます。

**移動** は選択したプレイヤーのそばへ安全にテレポートします。

**ここへ呼ぶ** は選択したプレイヤーに、自分の近くへ安全にテレポートするよう要求します。

どちらの場合も、目的地点の近くにある空き場所を使うよう試みます。

## 制限

Entangled Worlds 対応は引き続き実験的です。

**マルチプレイヤー中に大型または多関節のボスへ変身すると、性能が致命的に低下し、現在のゲームセッションが事実上壊れることがあります。**

Noita の状態を完全に同期することは非常に難しく、特に次の要素が同時に変化する場合は困難です：

- ピクセルワールド
- マテリアル
- 物理オブジェクト
- 複雑なモブやボス
- 他の MOD の内容。

そのため MCM は、考えられるあらゆる状態の完全な同期を保証しません。

# NoitaPatcher と安全でない MOD

MCM の完全版には **NoitaPatcher** が含まれています。

Noita の通常の MOD 機能だけでは実現できない処理に使われます。特に次の仕組みの一部で利用されます：

- 複雑な変身後の復元
- ゲームエンティティの操作
- ゲームワールドの操作
- 一部マテリアルの配置
- 互換性の拡張。

そのため完全版では **安全でない MOD** を許可する必要があります。

NoitaPatcher は MCM の配布ビルドにすでに含まれているため、別途インストールする必要はありません。

# うまく動かない場合

## MCM が読み込まれない

展開後、次のファイルが存在することを確認してください：

```text
Noita/mods/metamorph_creative_menu/mod.xml
```

さらに以下を確認してください：

- **MOD** メニューで MCM が有効になっている
- 名前の前に **[x]** が付いている
- **安全でない MOD：許可** になっている
- 有効な MOD を使ってゲームを開始している。

## NoitaPatcher を使う機能が動かない

次のファイルがあることを確認してください：

```text
metamorph_creative_menu/NoitaPatcher/noitapatcher.dll
```

また、**安全でない MOD** が許可されていることを確認してください。

## 形態から戻れない

割り当てた復帰操作を試してください。初期設定は **TAB** です。

問題が繰り返す場合、不具合報告には次の情報があると役立ちます：

- モブの正確な名前
- 分かる場合は XML パス
- どの方法でその形態になったか
- 通常の復帰は動作するか
- 致命的ダメージを受けた場合だけ発生するか
- Entangled Worlds を使用しているか。

## Entangled Worlds の問題

次を確認してください：

- 参加者が同じ MCM バージョンを使っている
- Entangled Worlds のバージョン同士に互換性がある
- 他の MOD のマテリアルやモブに関する問題なら、参加者の MOD 構成が同じである。

# 不具合を報告する

[Issue を作成](https://github.com/zerodancing/Metamorph-Creative-Menu/issues)

役に立つ報告にするため、できれば次を記載してください：

- MCM のバージョン
- 何をしていたか
- 期待した結果
- 実際の結果
- 関係するモブ、アイテム、パーク、マテリアルの名前
- Entangled Worlds を使用しているか
- 関係している可能性のある他の MOD
- エラー文または該当するログの一部
- 状況が分かりやすくなる場合はスクリーンショットや動画。
