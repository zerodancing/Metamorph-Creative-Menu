# 설치

1. [최신 버전의 모드를 다운로드](https://github.com/zerodancing/Metamorph-Creative-Menu/releases/download/latest-build/Metamorph-Creative-Menu.zip)합니다.
2. Noita를 실행하고 메인 메뉴에서 **모드**를 엽니다.
3. **모드 폴더 열기**를 누릅니다.
4. 다운로드한 압축 파일의 `metamorph_creative_menu` 폴더를 열린 `mods` 폴더로 옮깁니다. 이미 `metamorph_creative_menu`가 있다면 기존 폴더를 삭제하고 새 폴더로 교체하세요.
5. 모드 폴더를 닫습니다.
6. 모드 메뉴에서 **새로고침**을 누릅니다. 목록에 **Metamorph: Creative Menu**가 나타나야 합니다.
7. **안전하지 않은 모드**를 눌러 글자가 빨간색이 되고 **안전하지 않은 모드: 허용됨**으로 표시되게 합니다.
8. 모드 이름을 눌러 밝게 표시되고 이름 앞에 **[x]**가 붙게 합니다. 이 상태가 모드가 활성화된 상태입니다.
9. **활성화된 모드로 새 게임 시작**을 누릅니다.
10. 게임 모드를 선택하고 플레이합니다.

# 전체 버전과 Steam 창작마당 버전

이 GitHub 페이지에서 제공하는 빌드는 MCM의 전체 버전입니다. NoitaPatcher와 안전하지 않은 모드 권한이 필요한 기능이 포함되어 있습니다.

[Steam 창작마당 버전](https://steamcommunity.com/sharedfiles/filedetails/?id=3785170245)은 별도로 설치합니다. 이 버전에는 NoitaPatcher와 안전하지 않은 모드 권한이 필요한 전체 버전 기능이 포함되어 있지 않습니다.

두 버전을 동시에 설치하거나 활성화하지 마세요.

# 모드 소개

**Metamorph: Creative Menu (MCM)**은 Noita용 크리에이티브 메뉴와 도구 모음입니다.

주문, 완드, 아이템, 재료, 퍽, 효과, 생물, 변신, 날씨, 전역 세계 규칙, 순간이동 기능을 하나의 인터페이스에 모아 놓았습니다.

MCM은 자유로운 크리에이티브 플레이에도, Noita의 작동 방식을 시험하는 데에도 사용할 수 있습니다. 많은 작업은 단순히 새 엔티티를 생성하는 방식이 아니라, 이미 존재하는 완드, 아이템, 형태, 퍽 또는 세계의 상태를 고려해 처리됩니다.

**Entangled Worlds는 필요하지 않습니다.** 설치하지 않아도 MCM은 완전한 싱글플레이 모드로 작동합니다. Entangled Worlds를 설치하면 추가 실험적 멀티플레이 기능이 활성화됩니다.

# 조작과 인터페이스

| 동작 | 키 |
| --- | --- |
| 크리에이티브 메뉴 열기/닫기 | **F4 또는 TAB** |
| 인간 형태로 돌아가기 | **변신 중 TAB** |
| 생물 조종 | **G** |
| 선택한 재료로 그리기 | **마우스 가운데 버튼** |

MCM 패널은 일반 인벤토리 인터페이스에서도 사용할 수 있습니다.

키 지정은 **조작** 항목이나 모드 설정에서 변경할 수 있습니다.

키를 지정하는 동안:

- **DELETE / BACKSPACE** — 지정 해제
- **ESC** — 취소
- **R** — 기본값 복원
- **모두 초기화** — 확인 후 모든 키 지정을 기본값으로 복원.

같은 키 조합이 여러 동작에 지정되면 MCM이 충돌을 표시합니다.

## 크리에이티브 메뉴 창

창은 다음과 같이 조작할 수 있습니다:

- 이동
- 너비와 높이 변경
- 가장자리와 모서리를 끌어 크기 조절
- 최소화
- 닫기
- 기본 배치로 복원.

창 크기, 위치, 마지막으로 열었던 항목은 게임을 종료해도 저장됩니다.

큰 목록은 스크롤을 사용하며 현재 창 크기에 맞춰 자동으로 조정됩니다.

## 검색

다음 목록에서 검색할 수 있습니다:

- 주문
- 아이템
- 재료
- 퍽
- 생물.

표시 이름뿐 아니라 영어 이름, 현지화 키, 기술 식별자, XML 경로도 검색에 사용할 수 있습니다.

검색은 대소문자를 구분하지 않으며, 충분히 긴 단어에서는 작은 오타도 어느 정도 허용합니다.

MCM 인터페이스는 11개 언어를 지원합니다. 일반 게임 콘텐츠는 가능한 경우 Noita 자체 번역을 사용합니다.

# 주문

주문 항목에서는 목록뿐 아니라 현재 플레이어가 실제로 보유한 주문도 직접 다룰 수 있습니다.

동시에 다음을 사용할 수 있습니다:

- 현재 완드 슬롯
- **항상 시전**
- 주문 인벤토리
- 주문 목록.

## 빠른 교체

완드의 특정 슬롯을 선택한 뒤 목록에서 원하는 주문을 좌클릭하면 해당 슬롯에 주문이 배치됩니다.

## 끌어서 놓기

기존 주문은 다음 위치로 옮길 수 있습니다:

- 완드 슬롯 사이
- **항상 시전**으로
- **항상 시전**에서 일반 슬롯으로
- 주문 인벤토리의 특정 슬롯으로
- 인벤토리에서 완드로
- 게임 세계로
- 휴지통으로.

기존 카드의 경우 MCM은 새 복사본을 만들기보다 원래 게임 엔티티 자체를 옮기려고 합니다. 이를 통해 다른 모드가 추가한 상태를 포함해 이미 변경된 카드 상태를 유지할 수 있습니다.

새 목적지가 확정되기 전에는 원래 주문이 제자리에 남습니다. 실패하거나 허용되지 않은 작업이 원래 카드를 없애서는 안 됩니다.

## 항상 시전

항상 발동되는 주문에는 별도 영역이 있습니다.

일반 슬롯과 **항상 시전** 사이를 옮길 때는 완드 용량을 고려하여 일반 슬롯 구조가 올바르게 유지되도록 합니다.

## 실행 취소 / 다시 실행

완드 내부 변경에는 제한된 **실행 취소 / 다시 실행** 기록이 있습니다.

완드 자체의 상태만으로 안전하게 복원할 수 있는 작업에 적용됩니다.

실제 주문을 외부 게임 세계나 일반 인벤토리로 옮긴 경우 완드 상태만 되돌려서는 항상 정확하게 복원할 수 없으므로, 이런 작업은 언제나 실행 취소할 수 있는 것은 아닙니다.

# 완드

MCM에는 현재 사용 중인 완드를 위한 전체 편집 기능이 있습니다.

다음 항목을 변경할 수 있습니다:

- 슬롯 수
- 시전당 주문 수
- 재충전 시간
- 시전 간격
- 확산
- 투사체 속도 배율
- 최대 마나
- 마나 충전
- 반동 회복
- 완드 레벨
- 셔플
- **재충전 없음** 모드.

외형과 관련 설정도 변경할 수 있습니다:

- 표시 이름
- 잠금
- 완드 이미지
- 이미지 위치
- 발사 위치.

완드 외형을 선택할 수 있는 시각적 목록도 제공됩니다.

## 완드 프리셋

완드 상태를 저장하고 나중에 다시 사용할 수 있습니다.

저장되는 내용:

- 능력치
- 마나
- 외형
- 일반 주문
- **항상 시전**
- 카드 배치
- 남은 사용 횟수
- 카드 고정 상태.

저장한 완드는 다른 게임 세계와 이후 Noita 실행에서도 사용할 수 있습니다.

### 적용

**적용**은 저장한 상태를 플레이어가 현재 들고 있는 완드에 적용합니다.

### 복사

**복사**는 저장한 상태로 별도의 완드를 생성합니다.

빠른 인벤토리에 적절한 빈칸이 있으면 새 완드를 그곳에 넣습니다. 없으면 게임 세계에서 플레이어 근처에 생성합니다.

생성을 정상적으로 완료하지 못한 경우 MCM은 완성되지 않은 엔티티를 삭제하려고 합니다.

# 아이템과 액체

## 아이템

목록 항목을 **좌클릭**하면 플레이어 근처에 아이템 하나를 생성합니다.

**우클릭**하면 아이템을 인벤토리에 직접 넣으려고 합니다.

아이템을 끌어서:

- 빠른 인벤토리의 알맞은 영역으로
- 메뉴 밖의 게임 세계에서 선택한 위치로

옮길 수도 있습니다.

유효한 대상 없이 메뉴 안에 놓으면 작업이 취소됩니다.

목록 항목은 원본 역할을 하므로 아이템을 생성해도 해당 항목은 사라지지 않습니다.

MCM은 Noita의 빠른 인벤토리가 완드 슬롯과 아이템 슬롯으로 나뉘는 기본 구조를 고려하며, 이미 들어 있는 아이템을 이유 없이 교체하지 않습니다.

## 액체

MCM은 선택한 액체가 들어 있는 실제 게임 용기를 만들 수 있습니다.

생성된 용기는 일반 Noita 아이템처럼 작동합니다:

- 인벤토리에 보관할 수 있음
- 세계에 버릴 수 있음
- 깨질 수 있음
- 내용물이 쏟아짐
- 일반 재료 반응에 참여함.

# 재료

재료 목록은 현재 Noita에 등록된 물질을 바탕으로 구성됩니다.

다음과 같은 여러 종류가 포함됩니다:

- 액체
- 가루
- 기체
- 불
- 고체
- 정적 재료
- 특수한 표시 방식을 사용하는 재료.

다른 활성 모드가 자체 재료를 Noita에 올바르게 추가했다면 MCM에도 나타날 수 있습니다.

## 재료 그리기

1. 재료를 선택합니다.
2. 브러시 크기를 선택합니다.
3. **그리기 시작**을 누릅니다.
4. 인벤토리를 닫습니다.
5. 게임 세계에서 지정한 그리기 버튼을 누르고 있습니다.

기본값은 **마우스 가운데 버튼**입니다.

인벤토리를 열면 그리기 모드가 종료됩니다.

## 재료의 동작

MCM은 장식용 입자가 아니라 게임 세계의 실제 재료를 배치합니다.

배치된 뒤에도 Noita의 일반 시뮬레이션을 따릅니다:

- 액체는 흐름
- 가루는 무너져 내림
- 기체는 퍼짐
- 불은 주변과 상호작용함
- 물질은 서로 반응함
- 불안정한 재료는 다른 물질로 바뀔 수 있음.

재료 종류에 따라 적절한 배치 방식을 사용하며, 일반적인 모드 기능만으로 제대로 처리하기 어려운 경우에는 NoitaPatcher의 추가 기능도 이용합니다.

# 퍽

## 퍽 생성

**좌클릭**하면 선택한 퍽을 게임 세계에 생성합니다.

일반 Noita 퍽과 같은 방식으로 획득할 수 있습니다.

## 퍽 획득

MCM에서는 다음 수량을 획득할 수 있습니다:

- 1개
- 10개
- 100개.

대량 획득은 한 프레임에 많은 무거운 작업을 처리하지 않도록 단계적으로 실행됩니다.

인터페이스에 진행 상황이 표시되며 이후 처리를 취소할 수도 있습니다. 취소하기 전까지 정상적으로 획득한 퍽은 플레이어에게 남습니다.

## 퍽 제거

퍽을 안전하게 제거하는 것은 획득하는 것보다 훨씬 어렵습니다.

일부 퍽은 여러 게임 시스템을 동시에 바꾸거나 엔티티를 생성하거나 하나의 공통 방식으로 되돌릴 수 없는 효과를 실행합니다.

따라서 MCM은 충분히 신뢰할 수 있는 역작업이 가능한 지원된 변경만 제거합니다.

다른 효과나 플레이어 설정을 불필요하게 초기화하지 않고, 해당 퍽 적용으로 만들어진 상태만 되돌리려고 합니다.

# 효과

MCM은 다음과 같은 지원된 상태를 적용하고 제거할 수 있습니다:

- 게임 효과
- 재료와 관련된 상태.

제거할 때는 퍽이나 다른 게임 시스템에 속한 관련 없는 상태를 건드리지 않도록 합니다.

이를 통해 비슷한 상태를 모두 무조건 제거하지 않고 MCM이 다루는 효과만 정리할 수 있습니다.

# 생물과 변신

## 생물 생성

**좌클릭**하면 선택한 생물을 플레이어 근처에 생성합니다.

생물 카드를 메뉴 밖으로 끌어 게임 세계의 원하는 위치에 생성할 수도 있습니다.

지원되는 항목을 **우클릭**하면 현재 플레이어를 해당 형태로 변신시키려고 합니다.

## 형태 호환성

Noita의 생물은 내부 구조가 크게 다릅니다.

따라서 MCM은 정확한 XML 경로를 기준으로 변신 대상을 구분하며, 비슷한 생물을 자동으로 서로 같은 대상으로 취급하지 않습니다.

변신할 때는 선택한 형태의 기능을 사용하고, 필요하면 특정 생물에 별도 호환성 규칙을 적용합니다.

# 변신 후 복귀와 형태 사망

지정한 복귀 동작으로 인간 형태로 돌아갈 수 있으며 기본값은 **TAB**입니다.

MCM은 먼저 Noita의 일반적인 변신 종료 방식을 사용합니다. 복잡한 경우에는 NoitaPatcher를 통한 추가 복구 기능도 제공합니다.

또한 임시 형태가 치명적인 피해를 받는 지원된 상황도 처리합니다.

이 경우 MCM은 다음을 시도합니다:

- 죽은 형태의 시체 유지
- 인간 플레이어 복원
- 조작권 복원
- 인벤토리 유지
- 플레이어 관련 상태 복원.

이는 절대적인 무적 기능이 아닙니다. 다른 모드의 특수한 사망 방식, 호환되지 않는 모드, Noita 내부 오류는 일반 복구 절차를 우회할 수 있습니다.

# 기존 생물 조종

목록에서 형태를 고르는 것 외에도 MCM은 **게임 세계에 이미 존재하는 생물**을 조종할 수 있습니다.

기본 키는 **G**입니다.

알맞은 대상에 커서를 올리고 지정된 동작을 사용합니다.

MCM은 생물을 확인하고 호환되는 형태로 변신한 뒤, 성공이 확인된 경우에만 원래 엔티티를 세계에서 제거합니다.

변신에 실패하면 원래 생물이 그냥 사라져서는 안 됩니다.

이 기능은 MCM의 고정 목록에만 한정되지 않습니다. 다른 모드가 추가한 적절한 생물도 확인할 수 있지만 모든 외부 엔티티와의 보편적인 호환성을 보장하지는 않습니다.

# 플레이어

**플레이어**는 생물 목록의 특수 항목입니다.

일반적인 변신 형태가 아닙니다.

**좌클릭**하면 별도의 캐릭터를 만들고 MCM은 다음을 복사하려고 합니다:

- 플레이어 외형
- 최대 체력.

**플레이어** 항목을 **우클릭**해도 일반 플레이어가 이 엔티티로 변신하지 않습니다.

이미 인간 형태라면 아무 변화가 없습니다. 다른 생물로 변신한 상태라면 인간 형태로 돌아갑니다.

# 날씨와 시간

MCM에서는 다음을 변경할 수 있습니다:

- 시간대
- 날씨 프리셋
- 개별 지원 날씨 매개변수.

원하는 상태를 강제로 설정할 수도 있고, 나중에 해당 매개변수를 MCM의 제어에서 해제할 수도 있습니다.

예를 들어 시간을 강제로 설정한 뒤 Noita의 자연스러운 시간 흐름으로 되돌릴 수 있습니다.

# 세계 규칙

**규칙** 항목에서는 게임 세계의 동작을 더 깊이 변경할 수 있습니다.

구체적인 규칙에 따라 다음과 같은 값을 조절할 수 있습니다:

- 생물 간 관계
- 금
- 주문 사용
- 전장의 안개
- 특정 처치 보상
- 회복 드롭
- 피
- 중력
- 물리 동작
- 발차기 힘
- 물리 연결
- 낮밤 주기
- 기타 지원되는 전역 매개변수.

MCM 규칙의 핵심은 변경 사항이 **되돌릴 수 있도록** 설계되었다는 점입니다.

지원되는 설정에서는 원래 상태를 저장하고 값을 정상 상태로 되돌릴 수 있습니다.

배율을 사용하는 규칙은 이미 변경된 결과에 계속 곱하지 않고 기준 상태를 바탕으로 새 값을 계산합니다.

많은 엔티티나 물리 오브젝트를 변경해야 하는 작업은 버튼을 누르는 순간 세계 전체를 한꺼번에 처리하지 않도록 단계적으로 실행됩니다.

# 순간이동

MCM을 사용하면 준비된 게임 위치로 빠르게 이동할 수 있습니다. 예:

- 주요 진행 경로
- 신성한 산
- 큰 측면 지역
- 기타 지원 위치.

순간이동 전에 목적지 영역을 먼저 불러오고, 단단한 벽이나 장애물 안에 바로 나타나지 않도록 주변의 빈 공간을 찾습니다.

# Entangled Worlds

**Entangled Worlds / Noita Proxy는 선택 사항입니다.**

없어도 MCM은 싱글플레이에서 완전히 작동합니다.

Entangled Worlds를 설치하면 추가 실험적 멀티플레이 기능이 활성화됩니다.

안정적인 호환성을 위해 모든 참가자가 같은 MCM 버전을 사용하는 것을 권장합니다.

## 아이템, 완드, 주문

가능한 경우 세계의 아이템과 버린 주문은 Entangled Worlds의 일반 동기화 방식을 사용합니다.

인벤토리 변경도 Entangled Worlds를 통해 전달될 수 있습니다.

## 퍽

MCM이 생성한 퍽은 실제 게임 엔티티로 유지되며 가능한 경우 Entangled Worlds의 일반 세계 아이템 시스템을 통해 동기화됩니다.

## 재료

재료 그리기에는 실험적인 멀티플레이 지원이 있습니다.

MCM은 변경된 세계 영역을 동기화하여 다른 참가자에게도 결과가 나타나도록 합니다.

올바르게 작동하려면 상대방 게임에도 같은 재료가 존재해야 합니다. 사용하는 모드 구성이 다르면 모든 재료가 동일하게 표시된다고 보장할 수 없습니다.

## 날씨와 세계 규칙

지원되는 날씨 및 전역 규칙 변경은 Entangled Worlds를 통해 동기화할 수 있습니다.

## 변신과 생물 조종

Entangled Worlds 사용 시 변신에 추가 멀티플레이 지원이 적용됩니다.

이미 존재하는 생물을 조종할 때는 해당 대상의 네트워크 상태도 고려합니다. 원래 엔티티를 안전하게 삭제할 수 있다고 충분히 확신할 수 없다면 MCM은 그대로 남겨 두는 쪽을 선택합니다.

## 플레이어

Entangled Worlds로 플레이할 때도 특수한 **플레이어** 엔티티를 생성할 수 있습니다. 이 경우 생성한 사람의 스킨 색상을 복사합니다.

## 플레이어 간 순간이동

Entangled Worlds가 활성화되면 순간이동 항목에 이용 가능한 다른 플레이어가 표시됩니다.

**이동**은 선택한 플레이어 옆으로 안전하게 순간이동합니다.

**여기로 데려오기**는 선택한 플레이어에게 내 옆으로 안전하게 순간이동하도록 요청합니다.

두 경우 모두 목적지 근처의 빈 공간을 사용하려고 합니다.

## 제한

Entangled Worlds 지원은 여전히 실험적입니다.

**멀티플레이에서 크거나 여러 관절로 이루어진 보스로 변신하면 성능이 치명적으로 떨어져 현재 게임 세션이 사실상 망가질 수 있습니다.**

Noita의 모든 상태를 완전히 동기화하는 것은 매우 어렵습니다. 특히 다음 요소가 동시에 변할 때 그렇습니다:

- 픽셀 세계
- 재료
- 물리 오브젝트
- 복잡한 생물과 보스
- 다른 모드의 콘텐츠.

따라서 MCM은 가능한 모든 상태가 완벽하게 동기화된다고 보장하지 않습니다.

# NoitaPatcher와 안전하지 않은 모드

MCM 전체 버전에는 **NoitaPatcher**가 포함되어 있습니다.

Noita의 일반 모드 기능만으로는 구현하기 어려운 기능에 사용되며, 특히 다음과 같은 일부 처리에 쓰입니다:

- 복잡한 변신 후 복구
- 게임 엔티티 조작
- 게임 세계 조작
- 일부 재료 배치
- 확장 호환성.

따라서 전체 버전에서는 **안전하지 않은 모드**를 허용해야 합니다.

NoitaPatcher는 MCM 설치용 빌드에 이미 포함되어 있으므로 별도로 설치할 필요가 없습니다.

# 문제 해결

## MCM이 로드되지 않음

압축을 푼 뒤 다음 파일이 존재하는지 확인하세요:

```text
Noita/mods/metamorph_creative_menu/mod.xml
```

그리고 다음을 확인하세요:

- **모드** 메뉴에서 MCM이 활성화되어 있음
- 이름 앞에 **[x]**가 있음
- **안전하지 않은 모드: 허용됨**으로 표시됨
- 활성화된 모드와 함께 게임을 시작했음.

## NoitaPatcher를 사용하는 기능이 작동하지 않음

다음 파일이 있는지 확인하세요:

```text
metamorph_creative_menu/NoitaPatcher/noitapatcher.dll
```

그리고 **안전하지 않은 모드**가 허용되어 있는지 확인하세요.

## 형태에서 돌아올 수 없음

지정된 복귀 동작을 사용해 보세요. 기본값은 **TAB**입니다.

문제가 반복되면 신고할 때 다음 정보를 함께 적는 것이 좋습니다:

- 생물의 정확한 이름
- 알고 있다면 XML 경로
- 어떤 방식으로 해당 형태가 되었는지
- 일반적인 복귀가 작동하는지
- 치명적인 피해를 받은 뒤에만 문제가 발생하는지
- Entangled Worlds를 사용하는지.

## Entangled Worlds 문제

다음을 확인하세요:

- 참가자들이 같은 MCM 버전을 사용하는지
- Entangled Worlds 버전끼리 호환되는지
- 다른 모드의 재료나 생물과 관련된 문제라면 참가자들의 모드 구성이 같은지.
